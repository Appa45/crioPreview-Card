# Crio NFT Preview Card

Run locally:
1. Open a terminal in this folder.
2. Run `python -m http.server 5500`
3. Open `http://localhost:5500`

Before Crio submission:
- Replace submit.txt with ONLY your deployed project URL.
- Replace the GitHub link in index.html with your GitHub profile.
- If you are using the original Crio workspace, keep its existing assessment folder and run:
  chmod +x run_assessment.sh
  ./run_assessment.sh

Note: this standalone ZIP includes local placeholder image assets so it runs by itself. For the Crio assessment, prefer the official starter assets if they are supplied in your original workspace.
